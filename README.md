Щодо основних частин, проекту:
1) Фізичні розрахунки симуляції
2) удосконалення розрахунків за допомогою ML - опціонально
3) Web інтерфейс

<b> Щодо фізики </b>

На сьогоднішній момент ключовими є
- SPM (специфікація SPMe = with electrolite)
- Thermal model (специфікація Lumped thermal-electrochemical model)
- SEI (специфікація Zero-Dimensional Reaction Limited)

Само собою таке поєднання не забезпечує покриття 100% усіх електрохімічних процесів, однак точність має бути досить високою. Додатковим рішенням для покращення є ML, оскільки так можна уточнити попередню модель усякими нюансами, які неможливо врахувати в повній мірі. 

Подібна тема є завжди компромісом між швидкістю і точністю, тому серед багатьох моделей та апроксимацій були обрані саме ці. Вони описують справжні процеси в акамуляторах і не є просто абстракціями, однак використовують певні усереднення, щоб спростити обрахунки. Через величезну кількість процесів, модель відкрита для майбутнього розшинення і покращення навіть без фундаметальної зміни логіки та архітектури.

<b> Щодо ML </b>

Найбільш поширений варіант це Residual Learning (матрицю, яка підразовує залишкову похибку), оскільки для цього використовують  стандартну функцію втрат, тому шлях реалізації досить зрозумілий і очевидний. physics_prediction + residual_error = inference = фінальний розрахунок

Є й інший варіант це PINN, але тут ускладнення у тому, що треба зробити кастомну функцію втрат та інтегрувати в неї диференціальні рівняння, що є математично складним і ризиковим завданням. Якщо ми помилимось, то вона так і не збіжиться до мінімуму та результату ми не отримаємо.

Є ще й інші середні варіанти типу LSTM та Gaussian Process Regression, однак вони більш специфічні
