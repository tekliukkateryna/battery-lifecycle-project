<b> Щодо фізики </b>

На сьогоднішній момент мені здається ключовими є
EMC (Equivalent Circuit Model) (2-RC), який дасть State of Charge
Thermal model, яка рахує напрівання акамулятора під час роботи відносто SoC
Arehenius equesion, яке дає коефіцієнт прискорення хімічної рекії відносно температури 
SEI (Solid Electrolyte Interphase) це по факту основна хімічна причина деградації акамуляторів і для розрахунку треба ніби SoC та коефіцієнт прискорення хімічної реакії

Само собою це не все, але тут має допомогти ML, оскільки він навчиться уточнювати попередню модель усякими нюансами, які ми не пропишемо. 

+ у нас є завжди варіант PyBaMM і тоді сфокусуватися на математиці для ML у разі чого

<b> Щодо ML </b>

Найпростіший варіант це Residual Learning (матрицю, яка підразовує залишкову похибку), оскільки для нього мажна скористатися стандартною функцією втрат, а значить і всіма стандартними fit() та т.п. при бажанні або самим прописати, у будь-якому випадку придумувати щось особливе не треба. Типу physics_prediction + residual_error = inference -> і його віддаємо як відповідь на frontend.
