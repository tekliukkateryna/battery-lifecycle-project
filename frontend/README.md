# Frontend — LG M50T SPMe Digital Twin Workstation

Інтерактивний 3D-інтерфейс електрохімічного Digital Twin для літій-іонного акумулятора LG INR21700-M50T, побудований на Three.js r128.

---

## Структура файлів

```
frontend/
├── index.html          — HTML-розмітка: хедер, 3D-вʼюпорт, панелі керування, телеметрія
├── style.css           — CSS-стилі: кольорова палітра, лейаут, бейджі, елементи керування
├── app.js              — JavaScript: 3D-сцена, фізика частинок, адаптер FastAPI, логіка UI
├── assets/
│   └── 45.glb          — 3D-модель акумулятора (geometry_0, текстура shaded.jpg)
└── README.md           — ← цей файл
```

## `VISUAL_CALIBRATION` — Головний пульт ручного налаштування

Усі візуальні параметри сконцентровані в об'єкті `VISUAL_CALIBRATION` на початку файлу `app.js` (рядки 10–60). Змінюйте лише **числові значення** — перезавантажте сторінку, щоб побачити результат.

### 1. Позиціонування 3D-моделі та прозорість корпуса

| Параметр | Рядок | Поточне значення | Опис | Діапазон |
|---|---|---|---|---|
| `modelScale` | 12 | `3.4` | Масштаб моделі у вʼюпорті | 1.0 – 6.0 |
| `modelRotationY` | 13 | `0.0` | Обертання моделі навколо осі Y (радіани) | 0.0 – 6.28 (2π) |
| `modelOffsetY` | 14 | `-0.10` | Вертикальний зсув моделі | -1.0 – 1.0 |
| `housingOpacityActive` | 15 | `0.88` | Прозорість корпуса під час CHARGE / DISCHARGE (1.0 = непрозорий, 0.5 = дуже прозорий) | 0.50 – 0.98 |
| `housingOpacityIdle` | 16 | `1.0` | Прозорість корпуса в режимі IDLE | 0.80 – 1.0 |

**Приклади:**
- Зробити корпус більш прозорим при роботі: `housingOpacityActive: 0.75`
- Зробити корпус напівпрозорим навіть в IDLE: `housingOpacityIdle: 0.90`

### 2. Яскравість поверхні (PBR калібрування)

| Параметр | Рядок | Поточне значення | Опис | Діапазон |
|---|---|---|---|---|
| `modelMetalness` | 23 | `0.10` | Металевість поверхні. Менше = яскравіше (більше дифузного світла). Більше = темніше (більше дзеркальних відблисків, потребує HDR-карту оточення) | 0.02 – 0.30 |
| `modelRoughness` | 24 | `0.48` | Шерохуватість. Менше = блискучий/глянцевий. Більше = матовий | 0.20 – 0.80 |

**Приклади:**
- Акумулятор занадто темний: зменшіть `modelMetalness` до `0.05`
- Акумулятор занадто яскравий/білий: збільшіть `modelMetalness` до `0.18` або `modelRoughness` до `0.55`

### 3. Система освітлення

| Параметр | Рядок | Поточне значення | Опис | Діапазон |
|---|---|---|---|---|
| `lighting.ambientIntensity` | 28 | `0.95` | Загальне розсіяне навколишнє світло | 0.3 – 2.0 |
| `lighting.hemiIntensity` | 29 | `1.05` | Купольне світло (зверху біле, знизу сланцеве) | 0.3 – 2.5 |
| `lighting.keyLightIntensity` | 30 | `1.40` | Головне спрямоване світло (правий верхній кут) | 0.5 – 3.0 |
| `lighting.fillLightIntensity` | 31 | `0.95` | Заповнююче світло (лівий передній кут) | 0.2 – 2.0 |
| `lighting.rimLightIntensity` | 32 | `0.80` | Контурне світло (ззаду, окреслює силует) | 0.0 – 2.0 |
| `lighting.toneMappingExposure` | 33 | `1.22` | Загальна експозиція камери. Більше = вся сцена яскравіша | 0.80 – 2.0 |

**Приклади:**
- Загалом затемнити всю сцену: `toneMappingExposure: 1.0`
- Прибрати тіні ззаду: `rimLightIntensity: 1.5`

### 4. Межі руху іонів Li⁺ (Containment Box)

Усі значення — відносні пропорції від bounding box моделі (0.0 = лівий/нижній/передній край, 1.0 = правий/верхній/задній край).

| Параметр | Рядок | Поточне значення | Опис |
|---|---|---|---|
| `ionBounds.minXRatio` | 39 | `0.08` | Відступ від лівої стінки (Катод) |
| `ionBounds.maxXRatio` | 40 | `0.92` | Відступ від правої стінки (Анод) |
| `ionBounds.minYRatio` | 41 | `0.06` | Відступ від дна |
| `ionBounds.maxYRatio` | 42 | `0.62` | **Верхня межа.** `0.62` = 62% висоти, щоб частинки НЕ залітали в верхній контакт (busbar/pipe). Збільшіть до `0.75` щоб частинки піднялися вище |
| `ionBounds.minZRatio` | 45 | `0.14` | Відступ від передньої стінки |
| `ionBounds.maxZRatio` | 46 | `0.86` | Відступ від задньої стінки |

**Приклади:**
- Частинки вилітають з-під моделі: збільшіть `minYRatio` до `0.12`
- Частинки залітають у верхній контакт: зменшіть `maxYRatio` до `0.55`
- Частинки виходять за бокові стінки: зменшіть `maxXRatio` / збільшіть `minXRatio`

### 5. Параметри частинок Li⁺

| Параметр | Рядок | Поточне значення | Опис | Діапазон |

| `ionSize` | 51 | `0.075` | Розмір кожної частинки | 0.02 – 0.20 |
| `ionSpeedMultiplier` | 52 | `1.0` | Множник швидкості руху | 0.2 – 5.0 |

## 3D-лейбли (CATHODE / SEPARATOR / ANODE)

Три плаваючі бейджі прив'язані до 3D-координат моделі і проєктуються на 2D-екран щокадру. Вони рухаються разом із камерою при обертанні/зумі.

### Як змінити розташування лейблів

У функції `setupSpatialAnchors()` (рядки ~797–833 у `app.js`):

```javascript
// Пропорції вздовж осі X (від 0.0 = лівий край до 1.0 = правий край)
const xCathode   = cellBbox.min.x + sizeX * 0.22;   // ← змініть 0.22
const xSeparator = (cellBbox.min.x + cellBbox.max.x) * 0.5;  // центр
const xAnode     = cellBbox.min.x + sizeX * 0.78;   // ← змініть 0.78

// Висота підвісу лейбла над моделлю
anchorPos: new THREE.Vector3(xCathode, yTop + 0.52, zMid)   // +0.52 над верхом
anchorPos: new THREE.Vector3(xSeparator, yTop + 0.72, zMid) // +0.72 (вище, щоб не перекривався)
anchorPos: new THREE.Vector3(xAnode, yTop + 0.52, zMid)     // +0.52 над верхом
```

**Що змінювати:**
- `0.22` / `0.78` — горизонтальна позиція лейблів (ближче до краю = ближче до стінки)
- `+ 0.52` / `+ 0.72` — висота підвісу над моделлю (більше = вище від корпуса)

### Як повністю прибрати лейбли

**Варіант 1 — Сховати через CSS** (рекомендовано, швидко):
```css
/* Додайте в style.css */
.spatial-badge,
.labels-svg-overlay {
  display: none !important;
}
```

**Варіант 2 — Видалити з HTML** (повне видалення):
У `index.html` видаліть блоки рядків 97–113:
```html
<!-- Видалити: -->
<svg id="labels-svg-overlay" ...></svg>
<div class="spatial-badge badge-cathode" id="badge-cathode">...</div>
<div class="spatial-badge badge-separator" id="badge-separator">...</div>
<div class="spatial-badge badge-anode" id="badge-anode">...</div>
```

### Як змінити стиль лейблів

У `style.css` (рядки ~386–429):
- `.spatial-badge` — загальний стиль: фон (`background`), рамка (`border`), розмір шрифту (`font-size`)
- `.spatial-badge.badge-cathode` — рамка та колір тексту для катода
- `.spatial-badge.badge-separator` — рамка та колір для сепаратора
- `.spatial-badge.badge-anode` — рамка та колір для анода

## Підключення до FastAPI бекенду

Клас `SimulationDataProvider` (рядки 68–260 у `app.js`) автоматично перевіряє `http://localhost:8000/api/health` при завантаженні. Якщо бекенд доступний — данні приходять через `POST /api/simulate/step`. Якщо ні — використовується вбудована аналітична OCV-модель (Chen et al., 2020).

Змінити адресу бекенду:
```javascript
// app.js, рядок 70
this.baseUrl = config.baseUrl || 'http://localhost:8000/api';
```
